Aerie

A citadel above the clouds, drawn with no triangles: every pixel traces into shapes defined by code. Drag to orbit, scroll to zoom; stand still and it sharpens.

Shape code

The castle is citadel(p), its roofs roofs(p): distances in metres, Z up, the middle of the plateau at the origin — the same conventions and helpers (sdBox, sdCylinder, smin…) as CodeNodes in Blender. A line // @param name default min max becomes a slider. Ctrl+Enter runs it.
