# CodeNodes Geometry Nodes library

Everything here opens in plain Blender (5.0 or newer) with **no add-on installed**.

| File | What it is |
|---|---|
| `CodeNodes Library.blend` | 27 node groups marked as assets: the capabilities (terrain, scatter, walls, rooms, roofs, stairs, water, paths) and the parametric generators (conveyor, rack, pallet, forklift, AMR, six-axis robot arm, CNC machine, workbench, tank, control cabinet, safety fence, desk, column, dock door, door, window, light fixture). Every generator's sliders are group inputs; its colours are the default materials. |
| `blender_assets.cats.txt` | The catalogs they sort into: Terrain, Architecture/…, Factory/…, Furniture/… |
| `examples/factory.blend` | A 60 x 40 m light-assembly factory: docks, pallet racking, CNC row, two fenced robot cells, QA, offices. Planned, built and verified by the factory builder. |
| `examples/warehouse.blend` | A 72 x 48 m distribution warehouse: receiving and shipping docks round a racking hall. |
| `examples/house.blend` | A two-storey house with a stair. |
| `build_library.py` | Writes all of the above from the code (`codenodes/gn/library.py` and `codenodes/factory/`). |

## Using the library

1. *Preferences > File Paths > Asset Libraries*: add this folder.
2. In a Geometry Nodes editor or the Asset Browser, pick **CodeNodes Library** and drag a
   group in, or add it as a modifier. Generators make their geometry from nothing, so put them
   on an empty mesh object; capabilities like *CN Wall Network* and *CN Rooms* go on curve
   objects (see each group's description).

## What needs the add-on

The groups and example scenes don't. Planning a building from a spec (`plan_site`), laying
out equipment and verifying it are Python, so they stay in the CodeNodes add-on and its MCP
tools. That's how "make me a factory floor for …" works: the assistant writes a spec, the
add-on plans and builds it from these same groups and generators.

## Rebuilding

    blender -b --factory-startup --python geonodes/build_library.py            # writes here
    blender -b --factory-startup --python geonodes/build_library.py -- --out D --no-examples
    blender -b --factory-startup --python tests/test_geonodes_library.py       # checks it, no add-on

Build with the oldest Blender you support (5.0.1 here): newer versions open its files.
